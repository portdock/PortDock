# 검증 점검표 (2026-10-17)

배포 전에 프로그램마다 모든 버튼·입력·기능·화면 상태를 확인한다. 자동 조작(`e2e/`, tauri-driver + Edge WebDriver)으로 실제 프로그램을 띄워 누르고, 단계마다 캡처해 눈으로 본다.
표시: ✅ 통과 · ❌ 실패(→ 고친 커밋) · ⏸ 장비 필요(가상 COM 쌍 또는 실기) · 💰 돈 드는 장비(`docs/todo.md` «시험용 장비» 에 있음 — 없으면 괄호 안 대안으로)

(10/18 추가) 실기 항목은 «준비 → 순서 → 기대» 로 적는다. 기대와 다르면 ❌ 와 함께 캡처·통신 기록(파일로 저장)·문제 보고 창 «파일로 저장(.md)» 을 남긴다.
가상 COM 쌍은 com0com(무료) 같은 것으로 만든다. «처음 실행» 은 휴대판 zip 을 새 폴더에 풀어 `portdock-data` 가 빈 채로 켠 것을 말한다.

## ⑦ SCPI (10/19 새 앱)
상대는 실 SCPI 계측기(💰 todo.md «시험용 장비» 의 SCPI 계측기 1대 — 소형 전원·멀티미터, LAN 또는 RS-232). 없으면 PortDock Simulator 로 흉내(도움말 «Simulator 로 따라하기») — SC1~SC5 는 Simulator 로도 되고, SC6~SC9 는 실기로만 확인된다.
