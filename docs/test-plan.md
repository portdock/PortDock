# 검증 점검표 (2026-10-17)

배포 전에 프로그램마다 모든 버튼·입력·기능·화면 상태를 확인한다. 자동 조작(`e2e/`, tauri-driver + Edge WebDriver)으로 실제 프로그램을 띄워 누르고, 단계마다 캡처해 눈으로 본다.
표시: ✅ 통과 · ❌ 실패(→ 고친 커밋) · ⏸ 장비 필요(가상 COM 쌍 또는 실기)

## 공통 (5개 모두)
| # | 항목 | 기대 |
|---|---|---|
| C1 | 첫 실행 화면 | 오류 화면 없음, 모든 칸 보임, 가로 스크롤 없음 |
| C2 | 언어 전환 한국어↔English | 모든 글자가 바뀜, 빠진 번역 없음, 버튼 글자 줄바꿈·잘림 없음 |
| C3 | 창 최소 크기(900×560)·최대화 | 겹침·잘림 없음, 로그 영역만 늘고 줄어듦 |
| C4 | 어두운 테마(윈도우 설정) | 글자·테두리·강조색 모두 읽힘 |
| C5 | 설정 기억 | 껐다 켜면 마지막 설정·명령 목록·규칙이 그대로 |
| C6 | 잘못된 입력 | HEX 홀수 자리·없는 글자 → 미리보기에 오류, 보내기 막힘 / 숫자 칸에 글자·음수·범위 밖 → 막히거나 바로잡힘 |
| C7 | 시작 전 버튼 상태 | 보내기·반복·파일 저장은 꺼져 있음 |
| C8 | 로그 | 10만 줄 넘게 받아도 화면이 버벅이지 않음, 자동 스크롤 끄면 멈춤, 줄 누르면 상세, 지우기, 화면 내용 저장 파일 내용 |
| C9 | 파일로 계속 저장 | 대화상자 → 기록 시작(첫 줄 설정) → 멈춤, 파일 내용·시각 형식 |
| C10 | 보내기 | HEX/ASCII, 체크섬 8종 붙음, 끝 문자 CR·LF·CRLF, 미리보기 = 실제로 나간 바이트, 엔터로 보내기 |
| C11 | 반복 보내기 | 간격대로 나감, 끊기면 자동으로 멈춤 |
| C12 | 명령 목록 | 추가·이름 바꾸기·▶ 보내기·✎ 불러오기·✕ 삭제 |
| C13 | 오류 표시 | 오류 문구가 보이고, 다음 성공 때 사라짐 |
| C14 | 도움말 | ? 버튼·F1 로 열림, 찾기, 섹션 이동, Esc 로 닫힘, 언어 따라 바뀜 |
| C15 | 꺼진 이유 | 보내기가 꺼져 있으면 옆에 이유(먼저 연결·보낼 내용·상대 없음), 연결 중 잠긴 칸에 🔒 안내 |
| C16 | 확인 창 (손으로) | 명령 ✕, 규칙 ✕, 슬레이브 ×, 채우기 — 확인 창이 뜨고 «아니요» 면 그대로 |
| C17 | 처음 안내 | 기록이 비었을 때 할 일 안내, 규칙이 없을 때 예시 |
| C18 | 언어 전환 (전체) | 영어로 바꾸면 화면·오류·사건 줄(끊김 사유 등)·Modbus 풀이·도움말까지 영어 |
| C19 | 말풍선 | 칸·버튼에 마우스를 0.35초 올리면 설명이 뜸, 화면 밖으로 안 나감(아래쪽은 위로), 누르거나 스크롤하면 사라짐, 언어 따라 바뀜, 윈도우 기본 설명과 겹치지 않음 |
