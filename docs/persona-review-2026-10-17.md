# 사용자 입장 검토 (2026-10-17) — 실제 사용자처럼 따라가 본 결과

코드 읽기로 사용자 유형별 흐름을 끝까지 따라갔다(실행 안 함). 세 갈래:
- **S** = Serial·Modbus Slave (현장 엔지니어, 펌웨어 개발자, 경쟁 도구에서 넘어온 사용자, Modbus 마스터 개발자, 영어 사용자)
- **N** = TCP·UDP·Simulator (HMI 개발자, TCP 장비 펌웨어, UDP 브로드캐스트·멀티캐스트, 장비 없는 시뮬레이터 사용자, 영어 사용자)
- **D** = 설치·배포 여정 (오프라인 공장 PC, 사무실 개발자, 해외 사용자, 문제가 생겼을 때)

상태: ✅ 고침 · 🔧 진행 · ⏸ 다음 판(기능 추가) · 👤 사용자 할 일
