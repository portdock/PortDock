## 4. 릴리스 본문 초안 (v0.1.0)
**PortDock 0.1.0 — 첫 공개판.** 현장 하드웨어 시험용 무료 통신 도구 다섯 가지(윈도우 10·11, 64비트).
- **Serial** — 시리얼(COM) 송수신, USB 장치 정보·자동 재연결, 신호선, 프레임 구분 4가지, 체크섬 8종, Modbus RTU 풀이·요청 만들기, 명령 목록·반복, 파일 기록
- **Modbus Slave** — Modbus RTU 장비 흉내(표 4종, 슬레이브 여러 개, 장애 주입, 표 저장)
- **TCP** — 클라이언트·서버(여러 접속, 상대별 보내기, 에코, 자동 재접속, keepalive)
- **UDP** — 송수신, 보내온 상대 목록, 브로드캐스트·멀티캐스트, 에코
- **Simulator** — 규칙(받으면 → 답하기)으로 장비 흉내, 시리얼·TCP·UDP, 하트비트, 프로필 저장
- 공통: 한국어·영어, 도움말(F1), 말풍선, 밝게·어둡게, 글자 크기, 문제 보고(동의할 때만 전송)
- 받는 법: 설치판(`-setup.exe`, 관리자 권한 불필요) 또는 휴대판(`-portable.zip`, 설정이 exe 옆에). 아직 코드 서명 전이라 «Windows의 PC 보호» 가 뜨면 «추가 정보 → 실행». SHA256: `SHA256SUMS.txt`, 백신 검사: (VirusTotal 링크)
- 라이선스: GPL-3.0. 버그·요청: GitHub Issues 또는 프로그램 안 «!».
