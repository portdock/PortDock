## 4. 릴리스 본문 초안 (v0.1.0)
기능 문구는 코드 기준(`site/src/data/tools.ts`·README 와 같은 내용). 실기 점검(2절)을 마치기 전이므로 «검증됨»·«시험 완료» 같은 말은 쓰지 않는다.

**PortDock 0.1.0 — 첫 공개판.** 현장 하드웨어 시험용 무료 통신 도구 아홉 가지(윈도우 10·11, 64비트).
- **Serial** — 시리얼(COM) 송수신, USB 장치 정보·자동 재연결, 신호선, RS-485 송신 방향 제어, 프레임 구분 4가지, 체크섬 9종 + 사용자 정의 CRC, Modbus RTU 풀이·요청 만들기, 자동응답, 명령 목록·반복, 파일 기록
- **Modbus Slave** — Modbus 장비 흉내: 시리얼 RTU·Modbus TCP·RTU over TCP, 표 4종(32비트·실수·문자열 칸), 국번 여러 개, 값 자동 변화, 장애 주입(지연·무응답·CRC·MBAP 길이·예외), 내장 장비 31종 흉내, CSV 레지스터 맵·JSON 저장
- **TCP** — 클라이언트·서버·중계(모니터), 여러 접속·상대별 보내기, 에코, 자동 재접속, keepalive, Modbus TCP 프레임 구분
- **UDP** — 송수신, 보내온 상대 목록, 브로드캐스트·멀티캐스트, 에코
- **Simulator** — 규칙(받으면 → 답하기)으로 장비 흉내, 시리얼·TCP 서버·TCP 클라이언트·UDP, 응답 지연·무응답 흉내, 장비가 먼저 보내기(하트비트), 규칙 묶음 파일
- **Net Scan** — 랜카드 대역 핑·ARP 훑기(관리자 권한 불필요), MAC 제조사(내장 목록), 산업 포트 판정(502·2004·5000~5010·102·44818·4840 등)과 Modbus 장치 식별(FC 2B/0E), 장기 핑 감시(CSV), Wake-on-LAN
- **Modbus Master** — Modbus RTU·TCP·RTU over TCP 폴링, 여러 폴링 표, 타입 값(U16~F64·문자열·바이트 순서·40001 표기), 05·06·0F·10 쓰기와 바이트 미리보기, 국번·주소 범위 찾기, 내장 장비 31종 프로필, 통계, 값 CSV 기록, 추세
- **SCPI** — VISA 없이 LAN 소켓(5025)·RS-232, 질의·쓰기·읽기와 응답 시간, `*IDN?` 식별, 오류 큐 비우기, `*OPC?` 기다림, 반복 측정(값 표·추세·통계·CSV), 블록 데이터 HEX 미리보기·파일 저장. VXI-11·HiSLIP·USBTMC 는 아직 없음
- **Plot** — 시리얼·TCP·UDP 숫자를 실시간 그래프로: 글자 줄(구분자 자동)·`이름:값`·바이너리 프레임, 채널 32개·좌우 축, 멈춤·커서·두 점 Δ·확대, 받는 동안 CSV 기록, CSV·PNG 저장
- 공통: 한국어·영어, 도움말(F1), 말풍선, 밝게·어둡게, 글자 크기, 문제 보고(동의할 때만 전송)
- 받는 법: 설치판(`-setup.exe`, 관리자 권한 불필요) 또는 휴대판(`-portable.zip`, 설정이 exe 옆에). 아직 코드 서명 전이라 «Windows의 PC 보호» 가 뜨면 «추가 정보 → 실행». SHA256: `SHA256SUMS.txt`, 백신 검사: (VirusTotal 링크)
- 라이선스: GPL-3.0. 버그·요청: GitHub Issues 또는 프로그램 안 «!».
